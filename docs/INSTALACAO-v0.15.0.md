# Instalação v0.15.0

1. Fazer backup de `C:\Site\painel`.
2. Copiar o conteúdo do pacote `painel` sobre `C:\Site\painel`.
3. Copiar os arquivos da pasta `docs` para `C:\Site\docs`.
4. Executar `npm start`.
5. Abrir `http://localhost:3000/kernel`.
6. Navegar por módulos, clicar em ações de teste e confirmar novos registros.

## Validação mínima
- Painel inicia como v0.15.0.
- Dashboard e módulos continuam abrindo.
- Link `🧠 Logs` aparece no topo.
- A página `/kernel` mostra registros.
- Nenhum conteúdo sensível de formulário aparece em `data/kernel/logs.json`.
