# Checklist rápido — v0.25.1.6

1. Reiniciar o painel e abrir **ERP → Clientes**.
2. Conferir um cliente com somente celular: deve aparecer uma linha com `📱`.
3. Conferir um cliente com somente telefone: deve aparecer uma linha com `📱`.
4. Conferir um cliente com celular e telefone diferentes: devem aparecer duas linhas, `📱` e `☎`.
5. Conferir um cliente com o mesmo número nos dois campos: deve aparecer apenas uma linha com `📱`.
6. Pesquisar o cliente por cada um dos dois números e confirmar que ambos continuam localizando o cadastro.
7. Conferir a tela nos temas Claro e Black OLED.
