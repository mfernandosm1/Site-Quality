# Documentação Oficial — Painel Quality

Esta pasta é a referência oficial do projeto. Ela foi centralizada para reduzir arquivos soltos sem perder o histórico anterior.

## Ordem recomendada de leitura

1. `CONTEXTO_ATUAL.md` — estado atual e próximo passo.
2. `GUIA_DO_PROJETO.md` — regras que orientam qualquer alteração.
3. `ARQUITETURA_E_INTEGRACOES.md` — como os módulos se relacionam.
4. `STATUS_E_ROADMAP.md` — concluído, em validação e planejado.
5. `CHANGELOG.md` — histórico consolidado de versões.
6. `ESTOQUE.md` — documentação do módulo atualmente em evolução.
7. `MODULOS.md` — visão funcional dos demais módulos.
8. `OPERACAO_E_PUBLICACAO.md` — caminhos, publicação, backup e recuperação.
9. `ARQUIVOS_CRITICOS.md` — arquivos que exigem cuidado especial.

## Regra de conclusão

Uma versão só deve ser considerada concluída após:

- código implementado;
- teste manual realizado;
- backup quando necessário;
- documentação atualizada;
- status alterado de **em validação** para **estável**.

## Histórico preservado

Os documentos anteriores foram mantidos em:

`historico/documentacao-anterior/`

Eles não são mais a fonte principal, mas continuam disponíveis para consulta técnica e rastreabilidade.
