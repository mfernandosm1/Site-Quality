# PROJECT_GUIDE.md

# 📖 Guia Oficial da Plataforma Quality

> Este é o documento mais importante do projeto. Leia-o antes de alterar qualquer código.

---

# Objetivo

A Plataforma Quality é um sistema próprio desenvolvido para centralizar a operação da Quality Celulares.

Seu principal objetivo é oferecer uma plataforma rápida, estável, fácil de manter e preparada para evoluir continuamente.

---

# Filosofia

- Simplicidade acima da complexidade.
- Estabilidade acima de novidades.
- SEO faz parte da arquitetura.
- Automatizar sempre que possível.
- Reduzir o tempo operacional.
- Preservar compatibilidade.
- Documentar toda decisão importante.

---

# Perfil do Proprietário

- O projeto é administrado por uma única pessoa.
- Toda melhoria deve economizar tempo.
- Evitar excesso de configurações.
- Interfaces simples são prioridade.

---

# Estratégia Comercial

A plataforma não exibe preços por decisão estratégica.

Objetivos:
- evitar comparação direta;
- incentivar contato via WhatsApp;
- permitir negociação personalizada.

Essa decisão não deve ser alterada sem avaliação.

---

# Arquitetura

A plataforma é composta por:

- Site
- Painel Administrativo
- SEO
- Analytics
- Marketing IA
- Publicação
- Documentação (/docs)

Todos os módulos devem evoluir juntos.

---

# Regras Técnicas

- Nunca remover funcionalidades consolidadas sem necessidade.
- Preferir melhorias incrementais.
- Evitar dependências pesadas.
- Criar arquivos novos quando possível.
- Não reescrever módulos inteiros se pequenas alterações resolverem.

---

# Fluxo de Desenvolvimento

1. Planejar
2. Desenvolver
3. Testar
4. Documentar
5. Publicar

Nenhuma versão é considerada concluída sem documentação.

---

# O que nunca deve ser perdido

- SEO
- Performance
- Simplicidade
- Compatibilidade
- Organização

---

# Visão de Longo Prazo

A plataforma deverá evoluir para um ecossistema contendo:

- Site
- Painel
- Manual do Sistema
- Marketing IA
- Analytics
- CRM
- Orçamentos
- Clientes
- Aplicativo
- Integrações

Sempre preservando simplicidade e facilidade de manutenção.
