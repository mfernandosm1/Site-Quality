# Produtos — ordenação de variações (30/08/2026)

## Ajuste
- Adicionadas setas **↑ / ↓** nas opções de Cor, Armazenamento, RAM e Estado.
- A ordem pode ser alterada depois do cadastro sem excluir ou recriar a opção.
- Ao reordenar uma dimensão, as combinações internas são reordenadas para acompanhar a nova sequência.
- Dados existentes das combinações são preservados: imagem, estoque, preço ERP, custo, margem e demais campos.
- Primeira opção desabilita ↑ e última opção desabilita ↓ para evitar movimentos inválidos.
