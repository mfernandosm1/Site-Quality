# Changelog - Marketing IA

## V1

Primeira versão do módulo Marketing IA.

Incluído:

- Nova rota `/marketing`
- Tela inicial do gerador
- Integração com Gemini
- Geração de Story, Status, Grupos, Instagram/Facebook e Ideia de vídeo
- Referências
- Histórico

## V2

Melhorias de usabilidade.

Incluído:

- Histórico funcionando melhor
- Exclusão individual do histórico
- Limpar todo histórico
- Botões rápidos editáveis
- Reformulação de texto
- Ajuste para Gemini 2.5 Flash Lite
- Remoção do Status como card separado

## V3 - Bloco 1

Melhorias de estrutura de marketing.

Incluído:

- Story mais curto e direto
- Enquete / Interação Story
- Roteiro Reels
- Botões de ação rápida nos cards
- Nova versão por card
- Melhor estrutura de prompt para canais diferentes

## V3 - Bloco 2

Personalização e preparação comercial do módulo.

Incluído:

- Aba Configurações
- Configurações da empresa
- Personalidade opcional da marca
- Produtos principais
- Serviços principais
- Ações IA personalizadas
- Botão nativo 💰 Mais oferta
- Prompt principal usando dados da empresa
- Prompt de reformulação usando dados da empresa
- Documentação inicial em `Readme/MARKETING-IA.md`
- Changelog em `Readme/CHANGELOG-MARKETING-IA.md`
