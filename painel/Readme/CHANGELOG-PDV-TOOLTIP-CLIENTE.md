# PDV — Informativo da busca de cliente

## Ajuste

Atualizado o informativo (tooltip) exibido ao posicionar o mouse sobre a lupa do campo **Cliente** no PDV.

**Antes:** `Pesquisar cliente`

**Agora:** `Pesquisar / adicionar novo cliente`

A alteração deixa claro que a mesma ação permite localizar um cliente existente ou iniciar o cadastro de um novo cliente quando ele não for encontrado, sem adicionar um segundo botão e sem poluir a interface do PDV.
