# ERP Core

Pasta reservada para os serviços centrais do ERP Quality.

Nesta versão não há regras operacionais. A estrutura foi criada para receber gradualmente:

- identificação de empresa;
- IDs e auditoria;
- eventos internos;
- serviços de entidades;
- configurações do ERP;
- camada de persistência desacoplada.

Regra: nenhuma lógica de negócio deve ficar presa apenas às telas ou rotas.
